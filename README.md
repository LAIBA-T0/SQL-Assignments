# SQL Assignment 1 – BikeStores

**Name:** Laiba Touseef

T-SQL queries written for the Microsoft **BikeStores** sample database (SQL Server).

## File
- `SQL_Assignment_1.sql` – answers to all 15 questions (plus the bonus), each with a short comment.

## How to run
1. Restore / create the BikeStores sample database in SQL Server.
2. Open `SQL_Assignment_1.sql` in SQL Server Management Studio (SSMS) or Azure Data Studio.
3. Make sure `BikeStores` is selected, then run the file (or run each query one by one).

## Questions covered
1. Brand names
2. Products from most to least expensive
3. Customers in New York
4. Top 5 most expensive products
5. Products priced between $200 and $500
6. Customers whose last name starts with S
7. Mountain Bikes or Road Bikes
8. Orders not shipped yet
9. Product name, brand id and 15% discounted price
10. Unique customer cities (A–Z)
11. Active staff with full name and email
12. Cities from customers and stores combined (UNION)
13. Product ids in order_items that are not in products
14. 2016 products costing more than $1,500
15. Bonus: Trek 2016 and Surly 2017 products
